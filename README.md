# Year Two C Projects

This repository contains coursework and practical projects completed during
Year Two, first semester, for INF231.

## Projects

- **Expression formatting** (`Expretion_bien_forme/list`)  
  A C project for processing and checking expression formatting.
- **Tic-tac-toe** (`Fonayen_23V2370_tic_tac_toe_bis`)  
  A two-player console tic-tac-toe game.
- **Ludo** (`Ludo_christian`)  
  Console and graphical/SDL versions of a Ludo game.
- **Snake** (`snake_christian`)  
  Console and graphical/SDL versions of Snake.
- **Songo** (`songo_christian`)  
  Console and graphical/SDL versions of Songo.

Each project includes its C source files and, where applicable, a `Makefile`
and project report. The repository also preserves the existing compiled
programs and supporting assets that were part of the coursework directory.

## Technologies

- C
- Make
- SDL for graphical versions

## Building

Move into a project directory and run the commands provided by its
`Makefile`. For example:

```sh
cd snake_christian/Fonayen_snake_terminal
make
```

The exact dependencies may differ between console and SDL projects.
